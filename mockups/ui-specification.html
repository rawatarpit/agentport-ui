Honesty rules (never violated)

Applied to every screen, every state.

Unknown, never green

  • • Missing row renders unknown, never healthy zero
  • • Tenant with no push renders unknown
  • • Metric rows absent → null, never zero
  • • Sector benchmark with no peers → unknown, never fabricated

Draft ≠ live

  • • Editor saves are drafts until approved
  • • Nothing auto-enforces on save
  • • Dashboard labels draft vs deployed on every editor

RLS is the control

  • • Reads are tenant-scoped via agentport_is_tenant_member()
  • • service_role never reaches browser
  • • No second trust path

No secrets in UI

  • • No amounts, CVV, passwords, API keys
  • • No raw credentials persisted
  • • Tokens dropped, never stored
  • • Industry/sector is not PII, but is still tenant-scoped

Approvals decided elsewhere

  • • Queue renders with full context
  • • Decision lands through hosted approval path
  • • No browser approve button

Sector comparison is aggregate-only

  • • Never reads another tenant's raw rows
  • • Service-role RPC returns sector medians only
  • • No tenant names, no tenant IDs in comparison output

Why fewer options (sidebar reduction)

From ~15 items to ~7 plus conditional Setup.

Before (~15 items)

  • • Get started → Setup
  • • Go live → Go live
  • • Operate → Approvals, Ledger, Analytics
  • • Govern → Rules, Capabilities, Limits & stop
  • • Connect → Connect, User sessions, Team
  • • Insights → Marketing & Sales

Problem: abstract labels ("Operate", "Govern"), equal weight to everything, 3 competing "Go live" CTAs.

After (~7 items)

  • • Today → Approvals, Ledger
  • • Configure → Capabilities, Rules, Limits & stop
  • • Settings → Go live, Connect, User sessions, Team
  • • Setup (conditional, hides after draft)

Fix: merchant mental models (urgent / policy / infrastructure), one primary CTA per screen, Setup retires when done.
